# 03 — 风险扫描与隔离策略

**What to build:** 注入 fixture 中的候选块被逐条规则标注（规则 id、严重度、文本区间、解释），并按配置被丢弃、标记或降权；配置为阻断且存在高严重度风险时 CLI 返回非零退出码。

**Blocked by:** 02 — 信任评分（来源与内容分项）

**Status:** ready-for-agent

- [ ] 规则集覆盖：祈使式指令、角色/标记 token、隐藏或零宽字符、编码载荷、外泄短语、分隔符逃逸
- [ ] 每条发现含规则 id、严重度、文本区间、解释
- [ ] 隔离策略可配置：drop / mark / downrank
- [ ] 风险惩罚进入信任分与重排
- [ ] CLI 在"阻断 + 高严重度"时返回非零退出码，否则返回 0
- [ ] 误报语料：合法文档中的普通祈使句不应被高严重度标注，边界写入文档
