# 04 — 多文档冲突检测

**What to build:** 同一 subject 的数值、日期、百分比、单位不一致被报告为显式配对，冲突双方在报告中互相引用，并在信任分与重排中体现惩罚。

**Blocked by:** 02 — 信任评分（来源与内容分项）

**Status:** ready-for-agent

- [ ] claim 抽取覆盖数值、日期、百分比、单位；subject 来自元数据键或查询锚定词
- [ ] 冲突以显式配对出现在报告中，双方互相引用
- [ ] 相同取值不报冲突；不同单位不误判为冲突
- [ ] 一致性分项接入信任分；冲突惩罚进入重排
- [ ] fixture：冲突语料产生预期配对，无冲突语料产生空列表
- [ ] 边界：缺失 subject、无法解析的值、中英混排
