# 全部判定使用确定性启发式，不引入模型推理

Status: accepted (2026-11-06)

候选方向中的重排与信任评分，直觉上应由 cross-encoder 或 LLM 完成。本项目选择全部用确定性规则与可解释特征实现：单人一个月、MoonBit 无成熟推理运行时、离线可复现是硬约束。

## Considered Options

- **本地 Transformer 推理**：`laya` 仅覆盖 ModernBERT 编码器且无通用 embedding API；自建推理栈远超一个月。
- **调用远程 LLM API**：引入密钥、网络与费用依赖，验收无法离线复现，且与"纯 MoonBit 库"的定位冲突。

## Consequences

- 重排是特征加权（检索分数、信任评分、冲突惩罚、多样性），不是语义重排；效果上限低于模型方案。
- 注入检测是规则与信号组合（指令性句式、角色标记、隐藏字符、外泄指令），不是分类模型；需要在 README 中明确误报与漏报边界。
- 所有判定必须可追溯到具体信号，这同时满足验收标准中的"AI 可解释"。
