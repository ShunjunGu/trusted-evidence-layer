## 项目简介

moon-trust 是一个放在检索器和生成器之间的信任层。它不实现检索。

检索器返回候选块。moon-trust 检查这些候选块，给出三样东西：风险标注、信任评分、冲突列表。然后它重排候选块，输出证据上下文。

它解决一个具体问题。传统检索器能找到相关文本，但不能回答三个问题：这段文本是否可信，两段文本是否矛盾，文本里有没有恶意指令（提示词攻击）。现在每个应用都要自己写这些检查。moon-trust 把这一层做成公共库，任何检索器都能接。

之所以不把结果送到外部服务，是因为那会多一个运行时、一条网络链路、一个数据边界。之所以不用模型重排，是因为 MoonBit 现在没有成熟的推理运行时。moon-trust 用确定性规则，离线可跑，结果可复现。

现有基础：14 个提交；125 个测试在四个后端通过；CI 在三个系统通过；当前约 4,400 行 MoonBit。

## 核心功能范围

- 风险扫描：识别指令覆盖、角色标记、隐藏字符、编码载荷、外泄短语、分隔符逃逸。每条命中给出规则、严重度、原文区间、解释。
- 信任评分：按来源、内容、一致性三项打分。分数在 0 到 1 之间，分项写入报告。
- 冲突检测：抽取主体、单位、数值。不同文档对同一主体给出不同数值时，报告成对列出。
- 重排：检索分先归一化，再加信任分，再减风险与冲突惩罚。
- 证据上下文：在预算内组装文本。每条证据带 `[n]` 引用。风险和冲突放在附录。
- CLI：`scan` 读取 JSON，输出 JSON。退出码 0/1/2/3。同一输入两次输出一致。
- 配置：规则集、隔离策略、权重、冲突上限都可调。

不做：检索本身、模型推理、LLM 调用、内容审核、Web UI、持久化。
